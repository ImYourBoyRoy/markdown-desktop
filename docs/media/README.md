# README media

These documentation-only captures show the current Markdown Desktop frontend, themes, collapsed sidebar affordances, welcome actions, and workspace layout. They are not runtime assets.

`interface-tour.webp` is the single three-frame animated WebP used in the README. Its workspace frame uses the complete `workspace-dark.png` capture on the shared 1600×1000 canvas; it is padded to fit rather than cropped or stretched. `light-theme.webp` and `dark-theme.webp` are static WebP captures for readers who do not animate previews. `workspace-dark.png` is a lossless static capture so the application window edges and small interface text remain intact.

If the product UI changes materially, replace the captures and update the alt text in the root README at the same time. Keep screenshots free of private document contents and user-path information.
